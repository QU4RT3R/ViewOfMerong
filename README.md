# 전지적 메롱 시점

소~중형 인디 게임의 이야기를 짤 때 쓰는 스토리 설계 도구예요.
세계관, 캐릭터, 연표, 스토리를 한곳에 모아 두고, 위에서 내려다보듯 한눈에 볼 수 있어요.

- 스토리를 **큰 틀 → 날짜별 틀 → 세부 장면** 3단계로 나눠 써요. 장면은 소설처럼도, 대본처럼도 쓸 수 있어요.
- 글 어디서든 `[[이름]]`으로 용어·캐릭터를 연결하고, `??내용??`으로 아직 안 정한 부분을, `{{복선 이름}}`으로 복선을 표시해요. 놓친 것은 아래 상태 표시줄에 모여요.
- 년·월 단위 연표, 캐릭터 관계도, 깃허브 잔디 같은 캐릭터 비중표, 나무위키 보기 모드도 있어요.

설치나 가입 없이 브라우저에서 바로 쓰고, 작업은 `Story_YYMMDD_HHMM.json` 파일 하나로 저장해요.
브라우저에도 자동 저장되지만, 중요한 작업은 꼭 파일로 저장해 주세요.
